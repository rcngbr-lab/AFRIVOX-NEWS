# Compliance readiness checklist

| Obligation | Status | Evidence / owner |
|---|---|---|
| Editorial lifecycle and separation of duties | Implemented technically | `app/EditorialWorkflow.php`, transition log |
| Corrections and retained revisions | Implemented technically | revisions, correction notice, policy route |
| Privacy notice, retention periods and controller identity | Requires human/legal verification | management and qualified Rwanda counsel |
| Media organization/business registrations and any licence | Requires official registration/approval | RMC/RURA/RDB or other competent authority; verify current scope directly |
| Publisher, ownership and official contact disclosure | Requires management data | system settings and public policy pages must be completed |
| Personal-data controller/processor obligations | Requires human/legal verification | data map, lawful bases, processors, transfers and rights procedure |
| Advertising disclosures | Implemented technically in content type/schema; operations pending | commercial owner must approve creatives and invoices |
| Payment/subscription processing | Not activated | approved provider contract and test credentials required |
| MFA for privileged accounts | Not complete | select and integrate an MFA provider before production |
| Upload malware scanning and private originals | Not complete | storage/AV provider required |
| Backup and restore | Procedure documented; drill required | infrastructure owner |

No row marked “requires” or “not complete” is a compliance approval. Fees, dates and regulator requirements must be checked against current official sources before launch.
